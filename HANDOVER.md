- Flutter pinned to 3.47.x in CI (Material imports are deprecated in the Fall 2026 stable; migrate later with
  `dart fix --apply --code=migrate_design_widgets` and add `material_ui`).
- State management: Riverpod 2.x (`Notifier`). No Firebase yet.
- Premium theme unlock = 24 hours per rewarded ad (remote-configurable). Desktop (no ads) = all themes open for now.
- Signing: not in Gradle. CI signs the AAB (jarsigner) and APK (apksigner) from GitHub Secrets.
- Browse tab / all-files permission is OFF by default (Play policy).

## Known limitations / bugs
- (Session 8) Nothing of session 8 was compiled or run. Dash data is not encrypted. Cache of other apps cannot be cleared silently (Android rule).
- (Session 8) App sizes/cache/last-used need the owner to allow Usage access; without it only APK sizes are shown.
- Picked files are cache copies on Android (picker); recents may vanish if the OS clears cache.
- Office viewer is text/table only; legacy .doc/.xls/.ppt and OpenDocument not supported.
- Archive listing: ZIP/JAR/APK/AAB/TAR/TGZ only (RAR/7z not yet). Max 200 MB.
- Text viewer: first 2 MB; highlighting only for files under 300 KB / 4000 lines.
- EPUB: no links/footnotes jumping, no search, no bookmarks yet.
- Banner uses fixed 320x50 (adaptive banner later).
- iOS/desktop folders do not exist yet (Phase 2).
